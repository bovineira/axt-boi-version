# Nebula Contingency Ads

Site moderno e tech inspirado em axtron.io, desenvolvido com Next.js, React e Tailwind CSS.

## 🚀 Tecnologias

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (animações)

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Iniciar servidor de produção
npm start
```

## 🎨 Características

- Design dark e futurista
- Glassmorphism e efeitos de glow
- Animações suaves com Framer Motion
- 100% responsivo
- Background com efeitos de luz e partículas
- Todas as seções solicitadas implementadas

## 📝 Estrutura

- `app/page.tsx` - Página principal com todos os componentes
- `app/layout.tsx` - Layout base com metadata
- `app/globals.css` - Estilos globais e utilitários Tailwind
- `tailwind.config.ts` - Configuração do Tailwind

## 🔧 Personalização

Para alterar o nome da marca "Nebula Contingency Ads", basta fazer uma busca e substituição no arquivo `app/page.tsx`.
